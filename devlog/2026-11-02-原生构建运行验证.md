# 2026-11-02：原生构建运行验证

## 目标

启动 `dist\rclone_tray.exe`（Rust + Win32，v2.0.0）实际程序，验证核心功能与退出流程，而不是复跑单元测试或查看截图。

## 方法

- 使用隔离的 `RCLONE_TRAY_DATA_DIR`、`rclone.conf`（本地 remote）和临时挂载目录，避免影响用户现有配置与已安装的 Python 版实例。
- 工具令牌直接挂载被 WinFsp 拒绝（`c0000022`），因此以 UAC 提权运行 ctypes 驱动（`Start-Process -Verb RunAs`）。
- 通过 Win32 消息与控件 ID 驱动真实窗口：读取跨进程 EDIT 文本需用 `WM_GETTEXT`（`GetWindowText` 对另一进程的子控件返回空），托盘图标位置用 `Shell_NotifyIconGetRect`，托盘菜单用 `MN_GETHMENU`/`GetMenuItemRect` 配合真实指针点击。
- 证据为主窗口区域的桌面截图；`PrintWindow` 在本环境会产生异常的字符镜像，故弃用。

## 结果

24 项检查全部通过：挂载启停与读回、GUI 认证与 RC PID、关窗隐藏、托盘唤起、托盘退出确认、退出码 0、子进程与端口清理、源文件不受影响。详见 `docs\验收记录.md` 的 2026-11-02 章节与 `docs\evidence\native-2026-11-02-runtime.json`。
