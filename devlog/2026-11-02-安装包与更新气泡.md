# 安装包完善与更新气泡验收（2026-11-02）

## 目标

补齐 2.1.2 安装包的版本属性与运行中实例保护，让“发现新版本”气泡可点击并留下可核对证据，完成安装/升级/卸载与界面回归验收。

## 实现

- `assets/app.rc` + `build.rs`：资源脚本增加 `VERSIONINFO`，`build.rs` 用 `CARGO_PKG_VERSION` 替换 `@VERSION_COMMA@` / `@VERSION_STRING@` 占位符后交给 `windres`。EXE 现在带 `FileVersion 2.1.2`、`ProductVersion 2.1.2`、`CompanyName`、`ProductName`、`LegalCopyright`；安装包属性另由 Inno `VersionInfo*` 提供。
- `tools/installer.iss`：增加 `AppMutex=Local\rclone_tray_single_instance`，运行中的应用持有该互斥体时安装程序要求先关闭实例；补 `AppCopyright`、`VersionInfoCompany`、`VersionInfoCopyright`。
- `src/host.rs`：托盘回调新增 `NIN_BALLOONUSERCLICK`，点击“发现新版本”气泡进入“关于与诊断”，与气泡文案指向的下载入口一致。
- `src/ui.rs`：新建窗口时按目标页设置标题（`rclone_tray · {页名}`）。此前从托盘“关于与诊断”或气泡点击直接创建窗口时标题只有 `rclone_tray`，只有再次导航才更新。

## 验证

- `.\tools\build.ps1 -Test`：36 项单元测试通过、1 项忽略。发布构建 `dist\rclone_tray.exe` 2304512 bytes、`dist\rclone_tray_setup.exe` 21569902 bytes（2.1.2，提交 `303bf37c`，无未提交修改；SHA-256 见 `dist\build-manifest.json`）。
- 文件属性：EXE `FileVersion=ProductVersion=2.1.2`、`FileDescription=rclone_tray`、`CompanyName=Benincasamatch`；安装程序 `VersionInfo.FileVersion=2.1.2.0`。
- 安装流程（隔离副本：仅把 `AppId`、`AppMutex`、`DefaultDirName`、`OutputDir` 改到测试值，其余与发布脚本一致，避免覆盖本机 2.1.1 安装）：
  - `/VERYSILENT` 安装退出码 0；落地 `rclone_tray.exe`、`rclone\rclone.exe`、`build-manifest.json`、SHA-256 文件、`LICENSE`、`unins000.*`；HKCU 卸载项 `DisplayName=rclone_tray 2.1.2`。
  - 再次运行同一安装程序为覆盖升级，退出码 0。
  - 卸载 `/VERYSILENT` 退出码 0，安装目录、卸载项、开始菜单项全部移除；`%APPDATA%\rclone_tray\config.json` 的 SHA-256 前后一致（`446a9d56…178391`），用户配置保留。
  - `AppMutex` 实测：另编一份 `AppMutex` 指向真实互斥体的安装副本，在 2.1.1 运行时执行静默安装，退出码 1，日志为 `Setup has detected that rclone_tray is currently running.`，未创建目标目录。
- 新版本气泡：
  - 用同一份源码把版本号降到 2.1.0，在隔离目录构建后运行（当前 GitHub 最新为 2.1.1）。真实 WinHTTP 检查返回 `发现新版本 2.1.1。`，About 页状态文本可读；`Shell_NotifyIconW(NIM_MODIFY, NIF_INFO)` 返回 1。
  - Windows 通知库新增记录：`rclone_tray · 发现新版本`，正文 `发现新版本 2.1.1（当前 2.1.0）。 在“关于与诊断”可一键打开下载链接。`，处理程序 `NotifyIconGeneratedAumid_…`。同次隔离运行另有预期的 `未找到 rclone` 错误气泡记录。
  - 点击链路：向宿主窗口投递 `WM_TRAY_EVENT` + `NIN_BALLOONUSERCLICK`，实际创建前端窗口，标题为 `rclone_tray · 关于与诊断`，控件 511（检查更新）可见。
  - `tools\capture_ui.py --exe dist\rclone_tray.exe`：`status=pass`，15 张截图、50 项检查全部通过（`docs/evidence/native-stencil-checks.json`）。
- 已安装 2.1.1 的机器上，真实安装程序未执行（避免中断用户正在运行的挂载），测试均使用隔离副本。
