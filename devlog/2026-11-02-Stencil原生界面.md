# 2026-11-02：Stencil 原生界面

## 实现

依据用户指定的《Tern · Stencil 设计参考》，修改实际 Rust + Win32 前端，而不是历史 Python 界面。

- `src/ui_style.rs`：集中深/浅调色板、GDI 线性图标、按钮/复选框/挂载行、状态词与焦点边框；文字转换使用固定 UTF-16 缓冲区，GDI 资源恢复并释放。
- `src/ui.rs`：192/64px 侧栏、标题/说明/反馈区、76px 挂载列表、可复制详情、统一下拉菜单、DPI 字体和自适应布局。窄窗详情堆叠、操作换行，底部状态条固定。
- 标题栏使用可选 DWM 材质与圆角；`reduce_motion` 同时关闭转场与标题栏材质。内容区是实色分层，不宣称全窗口 Acrylic 或桌面穿透。
- 保留原生控件 ID/通知、后端命令、配置格式、保存/放弃守卫与托盘生命周期。新增侧栏折叠 ID 115。
- `tools/capture_ui.py` 替换为真实原生窗口驱动，不再截图 Python 版；使用隔离配置、PID 限定操作和桌面截图。

## 实际发现与修复

1. 低完整性工具进程无法切前台；通过 Windows UAC 授权启动截图驱动，驱动与测试实例完整性一致。没有启动测试挂载或 GUI。
2. 切页可能保留旧 owner-draw 导航选中面：布局后重绘所有控件。
3. 窄窗口只读面板可能盖住固定状态条：状态条置顶，全部子控件设置 `WS_CLIPSIBLINGS`；像素采样与截图验证面板不再覆盖它。
4. 主题放弃需要真实确认框；截图驱动确认后验证主题选项和颜色恢复，未绕过应用的草稿守卫。
5. 原 `dist/rclone_tray.exe` 被其他运行进程占用，构建后的复制失败。未结束该进程；发布新文件 `dist/rclone_tray-stencil.exe`，原文件及原构建清单保持不变。

## 验证

最终 `cargo build --release --locked` 成功。对发布目录中的新 EXE 实际运行深色与浅色场景：各 50 项检查通过、各 15 张桌面截图，正常退出码 0，临时配置内容保持不变并在结束后删除。

覆盖四页、搜索/无匹配/清除、稳定选择、Tab→状态筛选、编辑取消、720×520 窄窗操作可达、侧栏折叠恢复、下拉菜单、减少效果复选框、主题预览与确认放弃、状态条可见性及退出。未重跑单元测试；本次不声称验证挂载/GUI 启停、真实云 remote、自启、多显示器或其他 Windows 版本。

证据：`docs/evidence/native-stencil-checks.json`、`native-stencil-light-checks.json`；产物身份：`dist/stencil-build-manifest.json`、`rclone_tray-stencil.exe.sha256`。

使用：先从旧实例托盘退出，再运行 `dist/rclone_tray-stencil.exe`。应用不依赖 Python；截图工具需要 ctypes/Pillow 与交互桌面。
