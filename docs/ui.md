## 主页
- 挂载状态
	- 配置状态（未配置/配置名）
	- 挂载状态（检测中/挂载中/已挂载/异常/恢复中/已退出）
	- 当前配置
		- 名称
			- 地址
			- 位置
		- 状态
			- rclone状态
	- 保存
	- 停止
	- 跳转配置管理页面
- rclone位置
	- 自动检测
	- 指定exe文件
	- 跳转下载地址
- 配置管理
	- 新建配置  
	- 删除
	- 重命名
	- 编辑配置
	- 切换
		- 切换时检测挂载状态，必须在停止状态才能切换，附带停止服务按钮
	- 备份与恢复（webdav功能）
- 启动按钮
	- （检测挂载状态，只有已配置才能启动）
