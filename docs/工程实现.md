# 问题：
- 如何开始写代码？
- 如何把分散的代码变成一个完整的软件？
- 如何让别人也能安装和使用？

---
# 第一部分：如何开始程序编写？
按模块写
UI
│
Application Coordinator
│
├── Mount Manager
├── Config Manager
├── Tray Manager
├── Logger
├── Watchdog

编写顺序：
① Config Manager
        ↓
② Logger
        ↓
③ Rclone Service
        ↓
④ Watchdog
        ↓
⑤ Mount Manager
        ↓
⑥ Application Coordinator
        ↓
⑦ Tray
        ↓
⑧ GUI

每写完一个功能，应确认他们能够运行。所有功能写完后，再把他们链接起来。

---
# 第二部分：如何让别人也能使用？
准备发布。（Release）
整理项目，可以一眼看出项目结构。
打包，通过工具打包项目为exe文件。
安装，安装程序需要：
自动：

- 创建快捷方式
- 创建开始菜单
- 创建卸载程序
- 写注册表
- 设置开机启动（可选）

发布。

接下来，
- 创建完整目录结构。
- 创建所有模块和空类（接口对应的实现）。
- 编写 `main.py`，完成程序启动流程。
- 配置日志、配置文件、依赖管理（如 `requirements.txt` 或 `pyproject.toml`）。
- 初始化 Git，并保证程序能够启动，即使目前只是输出一行 `"Application started"`。
完成这一步后，整个项目就进入了"持续可运行"的状态，之后每实现一个模块，都可以立即运行、测试并提交，而不是等所有功能完成后再第一次运行。
