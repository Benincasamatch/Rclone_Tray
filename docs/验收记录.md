## 验证限制

- 工具默认进程令牌受限制：普通挂载收到 Windows c0000022，注册表写入拒绝；授权提权后真实挂载和事务成功。未将此受限令牌的失败宣称为正常用户会话成功。
- 官方 WinFsp 2.1.25156 MSI SHA-256 为 `073a70e00f77423e34bed98b86e600def93393ba5822204fac57a29324db9f7a`，与官方发布一致；Authenticode Valid，安装返回 0。安装保留，未自动卸载用户授权的依赖。
- 未重新启动 Windows，系统真实登录触发不作已验证声明；已验证命令格式、真实注册表读回、--autostart 来源逻辑和延迟取消。
- 未执行真实云存储授权/写入；使用 local remote 与临时文件。远端网络、权限、各云服务特例不作保证。
- 未进行完整可访问性合规、中文 IME 全分支和多显示器切换审计；已验证焦点/grab 释放、草稿退出与键盘安全实现，并实际观察 DPI 125% 表面。
- 旧 WebUI 首次下载仍依赖网络；缓存就绪成功不能替代冷下载网络可用性。
- 单 EXE 在不可写 TEMP 下由 PyInstaller bootloader 报 `Could not create temporary directory!`，尚未进入应用。隔离可写 TEMP 可启动；该限制在 README 说明。

## 构建验收

实际执行最终单 EXE（无 Python 依赖）并验证：使用空可执行路径发现内置 rclone；`--autostart --show` 启动临时 local 挂载和 GUI；读回 `packaged end to end proof`，RC 返回本实例 GUI PID。关闭主窗口隐藏且进程保留；系统托盘原生通知重新打开同一窗口；实际指针点击“退出”及确认后 EXE 返回 0，挂载消失。见[构建就绪截图](evidence/package-mount-ready.png)。

验收采用授权提权进程和独立可写 TEMP/TMP；不宣称工具受限令牌具备普通用户会话的系统访问能力。最终构建身份在 `dist/rclone_tray.exe.sha256` 与 `dist/build-manifest.json`，以文件实际 SHA-256 为准。
