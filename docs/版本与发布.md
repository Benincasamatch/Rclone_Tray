# 版本控制与发布

本文约定 rclone_tray 的版本号、git 提交、发布标签与安装包流程。软件版本指 `Cargo.toml` 的 `version`，与“配置 schema 版本”无关。

## 版本号

- 使用语义化版本 `x.y.z`：破坏兼容或大改 `x`，向下兼容的新功能 `y`，修复 `z`。
- 唯一来源是 `Cargo.toml`。`build.rs` 在编译时读取 git 提交、分支、未提交修改标记与构建时间；安装脚本和发布清单也从 `Cargo.toml` 读取版本，不手写重复版本号。
- GitHub 发布标签为 `v` + 版本号，例如 `v2.1.0`。更新检查只比较标签中的数字版本，忽略 `+build` 元数据，预发布（`-rc.1`）排序低于同号正式版。
- 更新检查忽略 GitHub 草稿和预发布，因此可以先进预发布验证，再发布正式版。

## 提交约定

提交信息使用 `type: 摘要`，摘要写实际行为，不写“更新文件”之类空话。常用类型：

| 类型 | 用途 |
| --- | --- |
| `feat` | 用户可见的新功能 |
| `fix` | 修复错误行为 |
| `refactor` | 不改变外部行为的结构调整 |
| `docs` | 文档、日志、截图说明 |
| `test` | 只改测试或验收工具 |
| `build` | 构建脚本、依赖、安装程序 |
| `chore` | 仓库维护 |

一次提交只表达一个可回滚的意图；构建产物 `dist/`、`rclone/`、运行日志与配置不提交。提交前运行 `.\tools\build.ps1 -Test`。

## 发布流程

1. 修改 `Cargo.toml` 的 `version`，同步 `Cargo.lock`（`cargo update -p rclone_tray --offline`），更新 README 与文档中会过期的版本描述。
2. 提交所有改动，确认 `git status --porcelain` 为空。
3. 运行 `.\tools\release.ps1 -Version 2.1.0`：脚本校验工作区干净、`Cargo.toml` 版本一致、标签不存在，执行 `build.ps1 -Test`，再创建 annotated tag。默认同时推送 `main` 与标签；本地演练可用 `-SkipPush`，跳过构建用 `-SkipBuild`（仅限已确认产物）。
4. 在 GitHub Release 上传 `dist\rclone_tray_setup.exe`、`dist\rclone_tray_setup.exe.sha256`、`dist\build-manifest.json`。便携版 `dist\rclone_tray.exe` 可一并上传。
5. 发布后从旧版本应用“关于与诊断 → 检查更新”验证：应显示新版本号、发布时间、说明和安装包大小，“打开下载页面”应直达该版本安装包。

## 更新检查契约

- 地址：`https://api.github.com/repos/Benincasamatch/Rclone_Tray/releases?per_page=10`，通过 WinHTTP 访问，连接 4 秒、接收 8 秒超时，响应上限 2 MiB。
- 只接受 `https://github.com/Benincasamatch/Rclone_Tray/releases/...` 的发布页和资产链接；其他地址不打开。
- 资产优先顺序：`rclone_tray_setup.exe` → `rclone_tray.exe` → 版本发布页。
- 更新模块只打开链接，不下载、不校验、不替换运行中的 exe；安装与升级由 Inno Setup 安装包完成，用户配置保留在 `%APPDATA%\rclone_tray`。
- 启动检查失败（离线、限流、DNS、证书）只写入“关于与诊断”，不弹错误气泡；手动检查显示原因并可重试。

## 安装包

- `tools/installer.iss` 使用 Inno Setup 6，按当前用户安装到 `%LOCALAPPDATA%\Programs\rclone_tray`，`PrivilegesRequired=lowest`，不写机器级注册表。
- 安装包包含 `rclone_tray.exe`、`rclone\rclone.exe`、`LICENSE`、`build-manifest.json` 与 exe 的 SHA-256 文件，创建开始菜单项和 HKCU 卸载入口；桌面快捷方式为可选任务。
- 同一安装程序覆盖升级；卸载不删除 `%APPDATA%\rclone_tray` 中的配置、日志和缓存。
- 构建机需要 Inno Setup 6（`winget install JRSoftware.InnoSetup`）或设置 `INNO_SETUP_ISCC`。
