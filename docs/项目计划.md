# rclone_tray 项目制作流程

> 版本：v1.0　|　状态：进行中　|　平台：Windows　|　语言：Python

## 1. 项目概述

**名称**：rclone_tray

**目的**：管理 rclone 的运行状态。Rclone 是一款命令行工具，用于在数十种云存储服务之间进行文件管理、同步和备份（官方文档：<https://rclone.org/docs/>）。

**核心功能**：

1. **系统托盘程序**：常驻托盘，动态显示 rclone 及各挂载的运行状态
2. **自动搜索 rclone 路径**：按优先级自动定位 `rclone.exe` 并用 `rclone version` 校验
3. **管理 rclone 启动状态**：
   - `rclone gui` 服务进程（Web GUI + RC API，v1.74+；旧版本回退 `rclone rcd --rc-web-gui`）
   - 多个 `rclone mount` 挂载进程
   - rclone 版本 / 可用性检测
   - rclone config 管理入口
4. **打开 GUI 界面**：通过 `rclone gui` 命令启动并一键在浏览器打开
5. **开机自动挂载**：注册表 `HKCU\...\Run` 开机自启 + 按用户配置（remote + 盘符）自动挂载

## 2. 技术选型

| 项 | 选择 | 说明 |
|---|---|---|
| 语言 | Python 3.10+ | 分支名 `python_frame` 确认 |
| 托盘 | pystray + Pillow | 跨平台托盘图标库 |
| 设置界面 | tkinter（标准库） | 挂载配置、rclone 路径等 |
| 进程管理 | subprocess | `CREATE_NO_WINDOW` 隐藏控制台窗口 |
| 开机自启 | winreg | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` |
| 配置存储 | JSON | `%APPDATA%\rclone_tray\config.json` |
| 日志 | logging + 文件 | `%APPDATA%\rclone_tray\logs\` |

## 3. 关键依赖（rclone 侧）

- `rclone gui`（v1.74+）：启动内嵌 Web GUI + RC API，`--no-open-browser` 不自动开浏览器，`--no-auth` 免认证，`--addr/--api-addr` 指定端口
- `rclone mount`（Windows 需先装 **WinFsp**）：`rclone mount remote:path X:` 挂载盘符；`--network-mode` 网络驱动器；`--vfs-cache-mode writes|full` 提供完整文件操作
- `rclone version`：校验可执行文件与解析版本
- `rclone rcd --rc-web-gui`：v1.74 以下旧版本 GUI 回退方案
- 配置文件：Windows 默认 `%APPDATA%\rclone\rclone.conf`

## 6. 设计要点

### 6.1 rclone 定位优先级
配置指定路径 → PATH（`shutil.which`）→ 常见安装目录 → 未找到（托盘提示，设置中可手动指定）。

### 6.2 进程生命周期
- GUI 服务与每个挂载均为独立 `subprocess.Popen`，带 `CREATE_NO_WINDOW`，输出重定向到日志
- 停止：`terminate()` → 等待超时 → `kill()` 兜底
- 退出托盘时停止 GUI 服务与全部挂载（子进程清理）

### 6.3 开机自启
- 注册表：`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 值 `rclone_tray`
- 命令：`"<pythonw.exe>" "<项目绝对路径>\main.py"`
- 自动挂载：启动后延迟 `mount_delay_seconds` 秒挂载所有 `auto_mount=True` 的挂载项，避免网络未就绪

### 6.4 安全与健壮性
- 单实例锁：命名互斥体 `Local\rclone_tray_single_instance`，防止双托盘
- GUI 默认 localhost `--no-auth`；可在设置中启用 user/pass
- 挂载前置依赖 WinFsp：未安装时挂载失败会记录日志并提示

## 8. 决策记录

- 仅 Windows；Python；WinFsp 为 mount 前置依赖（缺失时提示）
- 挂载配置通过 tkinter 对话框选择 remote + 盘符
- 退出托盘时清理全部子进程（不保留孤儿挂载）
- 排除：跨平台、系统服务化、rclone 自动更新、挂载崩溃自动重启（MVP 仅提示状态）
