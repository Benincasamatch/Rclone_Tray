## 2. 产品范围与用户任务

### 2.1 范围契约

| 编号 | 要求 |
| --- | --- |
| PR-01 | 保留 Windows 单用户托盘工具定位，提供真实 rclone 调用，不改成纯前端模拟原型。 |
| PR-02 | 保留 rclone 路径检测、版本显示、多个挂载、GUI 服务、认证配置、开机自启、自动挂载、主题和配置/日志入口。 |
| PR-03 | 重建信息架构、交互和状态管理；复用可验证的 rclone 调用、Windows 集成和图标资源，不为换皮更换整个技术栈。 |
| PR-04 | 保留已有用户配置和挂载稳定 ID；迁移失败不覆盖原文件，不静默恢复默认。 |
| PR-05 | 使用隔离配置、临时目录和可控进程进行验证；不拿用户真实远端数据做破坏性试验。 |

### 2.2 任务与边界

| 用户任务 | 成功结果 | 不包含的能力 |
| --- | --- | --- |
| 首次配置运行环境 | 检测到可执行文件与版本；明确 WinFsp、remote 是否可用 | 不自动安装依赖或伪造 remote |
| 管理挂载配置 | 新增、编辑、删除可持久化；失败保留输入 | 保存配置不自动启动；删除配置不删除远端文件 |
| 使用挂载 | 启动后确认就绪、打开挂载位置、停止并确认结果 | 不把进程创建成功当挂载成功 |
| 使用 rclone GUI | 服务就绪后打开当前实例；可查看失败原因并停止 | 不重写 rclone 网页文件管理器 |
| 配置启动行为 | 注册表状态与界面一致；自动挂载按全局和逐项规则执行 | 不扩展成 Windows 系统服务 |
| 定位问题 | 明确对象、阶段、错误和日志位置 | 不新增无依据的统计看板或遥测 |

不纳入本次范围：跨平台、手机/Web 独立客户端、多人角色系统、插件市场、rclone 自动更新、挂载崩溃自动重启、独立同步/备份任务调度。浏览器历史和 URL 路由不适用于主桌面窗口，改为定义应用内导航与恢复契约。

## 3. 现状与优先风险

以下为规划时的静态源码观察；实施对应功能前需要隔离复现，不能直接写成已验证缺陷。

| 观察 | 来源 | 重建要求 |
| --- | --- | --- |
| 保存设置后调用 `ProcessManager.rebuild()`，重新建立 GUI 与挂载对象 | `app/tray.py`、`core/processes.py` | 保存普通设置不得丢失已有进程引用或控制能力 |
| 主窗口与挂载编辑器直接关闭，没有草稿放弃判断 | `ui/settings_window.py`、`ui/mount_sheet.py` | 统一草稿基线、dirty、继续编辑和确认放弃 |
| 配置解析异常返回默认配置；写入使用直接覆盖 | `core/config.py` | 区分首次使用、损坏、读取失败与写入失败；保护原配置 |
| 运行判断主要为进程存活，启动返回值不表示就绪 | `core/processes.py` | 分离启动中、就绪、停止中、已停止和失败 |
| remote 空列表替换为 `remote:` | `ui/settings_window.py`、`ui/mount_sheet.py` | 真实空态与配置入口，不提供看似可用的假选项 |
| 延迟自动挂载调用全量启动，`start_all_mounts()` 没有逐项检查 `auto_mount` | `main.py`、`core/processes.py` | 明确全局开关、逐项开关和启动来源的关系 |

## 5. 架构与操作契约

### 5.1 分层与技术决策

| 层 | 职责与约束 |
| --- | --- |
| `ui/` | 导航、布局、输入、草稿、焦点和反馈；不直接写共享配置或控制子进程 |
| `app/` | 托盘与应用用例协调；统一操作入口、订阅和结果分发；主窗口与托盘不能各维护一套事实 |
| `core/` | 配置持久化、运行实例、rclone 适配、环境检测、Windows 集成；不依赖控件或像素参数 |
| `main.py` | 初始化、单实例、事件循环协调、启动任务和退出清理 |
| 打包与资源 | 保留 Windows 无控制台交付、图标与 rclone 资源；明确内置、旁置和用户指定可执行文件的优先级 |

保留 Python、tkinter、pystray、Pillow；界面统一为 `ui/widgets.py` 的 Canvas 自绘组件体系与 `ui/glass.py` 模拟玻璃（见架构决策 ADR-06），不维护第二套无关组件体系。具体模块拆分由阶段 1 的契约决定，不提前创建空模块。保留现有 rclone 版本分支能力；新旧分支分别验证，不用一个版本的成功替代另一分支证据。

### 5.2 业务规则

| 编号 | 已确认要求 |
| --- | --- |
| BR-01 | 挂载使用稳定 ID；名称不是身份；迁移、改名和运行记录关联不能丢失。 |
| BR-02 | 保存配置不启动进程；已保存配置、当前运行配置与编辑草稿分别表达。 |
| BR-03 | 普通设置保存不重启无关进程。运行中连接参数的变更要求先停止，不偷偷重启；显示名等非连接字段按明确契约处理。 |
| BR-04 | 删除挂载配置不删除远端文件；运行中的挂载先停止，再确认删除，说明对象与影响。 |
| BR-05 | 关闭主窗口保留托盘；退出应用需说明运行任务影响，取消延迟任务并确认本应用子进程停止。不管理或终止其他应用启动的 rclone。 |
| BR-06 | 自动挂载需同时满足全局策略与逐项 `auto_mount`；手动启动和系统自启的触发规则在阶段 1 固化，名称与行为必须一致。 |
| BR-07 | 多对象执行逐项返回结果；部分成功不得显示全量成功，不重复执行已成功项。 |

### 5.3 交互、UI 与数据规则

| 编号 | 要求 |
| --- | --- |
| IX-01 | 每个重要操作定义前置、输入、校验、处理中、成功、失败、取消、退出、并发与验收；错误包含对象、是否生效和下一步。 |
| IX-02 | 复杂配置使用独立草稿保存；失败保留完整输入；dirty 包括未失焦和非法输入；退出可继续编辑或确认放弃。 |
| IX-03 | 即时启停不受外层取消影响；界面明确已发生的动作，不暗示取消会撤销进程操作。 |
| IX-04 | 初载、保留旧数据的刷新、主动执行分开；同对象防重复执行，旧读取不能覆盖较新结果。 |
| IX-05 | 启动成功以就绪检查为依据；不可测进度只显示阶段文字。取消、超时不等于已停止，应重新确认事实。 |
| IX-06 | 弹层焦点进入/归还、Tab 范围、最上层 Escape、Enter 与 IME、后台刷新阅读位置有统一规则。 |
| UI-01 | 统一背景、表面、文本、边框、强调、成功、警告、错误、焦点和遮罩等 token；浅色/深色/跟随系统一致。 |
| UI-02 | 按钮、输入、列表、弹窗覆盖禁用、忙碌、错误、空态；状态不只依赖颜色。检查宽窄窗口、DPI、长路径和中英混排。 |
| UI-03 | 主要动作可用键盘完成；动效可减少，不影响操作结果，也不能代替完成证据。 |
| DC-01 | 持久配置、运行实例、派生摘要、展示偏好、编辑草稿和在途操作分开；在途状态不作为重启后的运行事实。 |
| DC-02 | 配置迁移保留 ID 与有效字段；原子写入，失败保留原文件和已确认状态；损坏不静默返回默认再覆盖。 |
| DC-03 | 操作结果区分成功、校验拒绝、状态冲突、运行错误、取消和部分成功；记录对象 ID、阶段和必要的运行配置快照。 |
| DC-04 | 凭据默认遮蔽；阶段 1 明确存储、日志、复制和浏览器入口政策；URL 与诊断输出不得暴露凭据。 |

## 7. 验收矩阵

矩阵是稳定验收基线。实际覆盖、证据与环境限制见[验收记录](验收记录.md)；尚未执行的系统登录、云盘特例和完整可访问性不得从实现完成推断通过。

| 编号 | 关联要求 | 场景 | 可观察结果 |
| --- | --- | --- | --- |
| AC-01 | PR-02、IA-04、IX-04 | 首次启动；缺 rclone、WinFsp 或 remote | 原因分别表达；提供正确入口，不生成假资源 |
| AC-02 | BR-01、BR-02、IX-05 | 添加→保存→启动→打开→停止挂载 | 配置和实例 ID 一致；保存不执行；就绪与停止由事实确认 |
| AC-03 | BR-03、DC-01 | 多挂载运行时修改主题或普通设置 | 既有进程保持受控，未被重建丢失，状态持续正确 |
| AC-04 | IX-02、IX-06 | 未失焦输入或非法输入→取消→继续编辑/放弃 | 继续编辑保留全部草稿；确认放弃不改已保存事实 |
| AC-05 | IX-01、IX-02、BR-07 | remote 无效、挂载点冲突、一个挂载失败 | 明确对象与原因；失败保留输入；其他成功项不受影响 |
| AC-06 | DC-02、PR-04 | 配置写入失败、损坏、旧配置迁移 | 不覆盖原文件或假报成功；迁移保留 ID 与有效字段 |
| AC-07 | IX-05、IA-02 | GUI 启动→就绪→浏览器打开→停止 | 打开当前实例；进程创建不等于就绪；停止结果可确认 |
| AC-08 | IX-01、DC-04 | GUI 端口占用、认证配置错误、启动失败 | 不误报就绪；错误可恢复；URL/日志/诊断不泄露凭据 |
| AC-09 | IA-05、IX-04、DC-01 | 托盘和主窗口交替操作，交错刷新 | 同对象状态一致；旧结果不覆盖新事实；不重复执行 |
| AC-10 | BR-04 | 删除运行中/已停止的挂载配置 | 先停止再删除；说明影响；远端文件和无关挂载不变 |
| AC-11 | BR-06、PR-02 | 自启来源、全局与逐项开关、延迟组合 | 只启动规则允许项；注册表读回与界面一致，失败不报成功 |
| AC-12 | BR-05、IX-05 | 延迟等待或进程运行时关闭窗口/退出应用 | 关闭留托盘；退出取消延迟并清理本应用进程，无晚到启动 |
| AC-13 | IX-06、UI-02、UI-03 | Tab/Enter/Escape、IME、弹层和后台刷新 | 焦点受控且归还；只关闭当前层；不误提交、不跳阅读位置 |
| AC-14 | UI-01、UI-02、UI-03 | 浅深主题、跟随系统、宽窄窗口、DPI、长路径 | 文字可读、主要动作可达、内容不裁切；减少动效仍可理解状态 |
| AC-15 | PR-02、PR-04 | 打包产物启动、旧配置读取、资源定位与完整业务链路 | 内置/旁置资源策略一致；无控制台；挂载/GUI/托盘可实际操作 |
| AC-16 | BR-02、BR-03、IX-03 | 有运行实例时编辑连接配置、执行即时启停后取消草稿 | 阻止不允许的热变更；保存/应用分清；取消不伪装撤销已执行操作 |

### 验证方法与安全边界

- 先验证可复现的现有问题，再验证对应改动；用户已报告的现象不重复运行以求“确认”。
- GUI、托盘、挂载必须真实启动并观察；截图只能证明视觉，不能证明保存、并发或进程清理。
- 首选临时配置、目录和受控本地挂载；不修改用户真实远端文件或暴露凭据。
- 注册表变更验证必须记录并恢复原值；涉及真实系统启动的场景单独记录，不能用函数测试冒充开机验证。
- 依赖、权限或相应 rclone 版本不可用时标记“未验证/阻塞”，说明已尝试步骤和缺失条件；不得缩小验收范围后宣称全部完成。
