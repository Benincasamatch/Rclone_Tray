# rclone_tray 重建架构决策

依据：[项目计划](项目计划.md)、[交互规格](交互规格.md)。此文件记录实现约束，运行结果见验收记录。

## ADR-01：保留桌面技术栈

保留 Python、tkinter、pystray、Pillow 和原生 Windows 标题栏。界面层统一为 `ui/widgets.py` 的 Canvas + PIL 自绘组件体系（见 ADR-06），不再使用 ttk；无需新 Web 宿主，不同时承担框架迁移和业务切换。

## ADR-02：唯一应用控制器

`app/controller.py` 持有已确认配置、revision、文件校验值、ProcessManager 和操作结果队列。Tk 主线程负责界面；单个后台执行器串行完成阻塞操作。托盘不触摸 Tk，只向控制器排队。主线程轮询运行快照与事件，既有草稿、选择和阅读位置不在后台刷新时重建。

更新配置调用运行管理的校验/更新接口，保留 Popen 身份；不再整体 rebuild。运行中改变连接字段或移除对象拒绝提交；显示名和偏好更新保留实例。所有调用方迁移到控制器，旧 open_settings、后台 Tk 线程和监控线程路径移除。

## ADR-03：安全持久化与外部冲突

JSON schema 2 保留旧字段和稳定挂载 ID。`load_config` 只有缺文件才返回默认，其他错误明确上报。临时文件写入/fsync/原子替换；提交时比较基线校验值，外部文件修改拒绝覆盖。内存事实在文件提交成功后更新；注册表失败回滚，无法回滚说明真实状态。

Windows DPAPI 加密 GUI 密码，密文只可由对应 Windows 用户/环境解密。旧明文加载为草稿基线，明确保存时迁移；不在启动时自动覆盖。使用 deepcopy 而非序列化往返复制配置，避免加解密副作用。

`RCLONE_TRAY_DATA_DIR` 隔离验证配置、日志和 GUI 缓存；`rclone_conf` 与 `RCLONE_CONFIG` 指定远端配置。可执行文件顺序为明确设置、打包 EXE 旁置、内置、PATH、已知目录；明确设置无效不偷偷退回另一个程序。

## ADR-04：实际就绪与凭据边界

运行状态为 stopped/starting/ready/stopping/failed；启动完成需验证归属进程和目标就绪，停止完成需确认退出及挂载消失。失败保留引用与可重试入口。启动等待检查取消事件，退出先阻止提交再清理所有拥有实例。

GUI 保留现代 gui 与旧 rcd 分支，启动前检查端口占用，认证只交给浏览器登录/HTTP 认证，不把 user/pass 放入 URL。捕获 rclone 输出并脱敏，避免原始自动登录链接落盘。服务健康检查使用配置认证而不是把 401 当宕机。

## ADR-05：交付与证据

源码验证之后使用 PyInstaller 生成无控制台单 EXE，内置 rclone 与图标。打包文件再次实际运行；SHA-256 与体积作为交付身份。桌面截图、真实挂载读回、浏览器服务、启动注册表读回及退出进程结果分别记录；无法真实登录启动时明确保留边界，不虚报全部开机验证。

## ADR-06：模拟玻璃与单一组件体系

按《Tern · Stencil 设计参考》重写 `ui/`。Tkinter 没有 `backdrop-filter`，Win11 Acrylic/Mica 只能作用于整窗且 Tk 客户端区无法逐面板透明，因此选择**模拟玻璃**：`ui/glass.py` 的 `Backdrop` 绘制环境光渐变，`GlassPanel` 按自身在最近外层表面中的位置裁剪位图并叠加 RGBA 令牌与描边，`Clear` 作为透明布局容器；子控件底色在表面渲染后按中心像素采样校正。透明失效时仍是完整可用的深色界面（规范 §9.3）。

重绘由 `Backdrop` 统一调度：请求合并为一次自顶向下的子树遍历，尾随防抖 20ms、最长推迟 80ms；只渲染可见表面，隐藏页面在映射时再渲染。已验证的约束：Tk Canvas 每次 `configure()` 都会按自身 width/height 重新请求几何，容器型表面渲染时不得调用 `configure`；隐藏页面内控件仍带 mapped 标志，可见性判断必须用 `winfo_viewable`。

组件体系单一化：按钮、输入、组合框、下拉、开关行、列表、文本区、滚动容器、浮层、提示全部实现 `apply_theme(bg)`，主题切换不重建控件；编辑器与确认框各自拥有 Backdrop，不再依赖主窗口的样式表。自动化工柄见 `ui/settings_window.py` 与 `ui/mount_sheet.py` 的类文档字符串；截图证据由 `tools/capture_ui.py` 在隔离沙箱生成。
