# rclone_tray 交互规格

本文件是重建实现契约，不是运行验收报告。范围与稳定需求编号见[项目计划](项目计划.md)；验证结果另记。

## 产品与信息架构

单用户 Windows 本地应用；鼠标和键盘，系统托盘与主窗口共享状态。主窗口原生标题栏，关闭窗口留托盘；退出应用单独确认并停止本应用拥有的进程。不提供云端角色管理、独立 Web 客户端或远端文件删除。

- 挂载：默认首页。名称、remote、挂载位置、状态可搜索和按状态筛选；条件 AND、文本不区分大小写。单对象选择，选中对象在刷新后按 ID 保持；无数据与无匹配分别说明。工具栏有新增、编辑、删除、启停、打开、日志及批量启停。
- rclone GUI：运行状态和启停/打开独立于认证配置草稿。打开网页不自动启动；等待就绪完成后才能打开。不会向 URL 注入用户名或密码。
- 设置：rclone 可执行文件、rclone 配置文件、主题、系统自启、自动挂载延迟和减少动态效果。
- 关于与诊断：版本（含 git commit、分支与构建时间）、WinFsp、配置与日志目录、官方文档；显示依赖错误但不展示凭据。启动后由后台操作线程检查 GitHub Releases，发现更高正式版本时发送一次托盘气泡提醒；页面显示最新版本、发布时间、更新说明与资产大小，并提供“打开下载页面”。更新检查只读，不下载或替换运行中的 exe。
- 托盘：启停、打开、挂载子菜单、系统启动偏好、主窗口与退出。复杂编辑定位主窗口。

导航保留当前对象与查询，切页重置页面滚动；后台刷新不修改草稿或滚动位置。编辑未保存时离开先确认。重复打开只唤起现有前端；关窗销毁 Win32 窗口，托盘宿主与后端继续运行。

## 实体和数据

- MountConfig：稳定 id、显示 name、remote:path、mount_point、vfs_cache_mode、network_mode、read_only、auto_mount、volname。改名不换 ID。
- AppConfig：rclone_path、rclone_conf、GUI 认证及自动启动、系统自启、自动挂载、延迟、theme、reduce_motion、mounts。JSON schema 2；仅不存在才返回默认；损坏保持原文件。
- 运行实例：状态、PID、消息、日志路径与启动配置快照。只管理本应用创建的子进程，不接管外部 rclone。
- 草稿：原始输入、基线 revision、dirty；会话内存在。非法输入和未失焦文本也是修改，失败不丢失。
- 在途操作：对象 key、action、busy、结果；不写入配置。结果区分完成、拒绝、运行失败、取消、部分成功。

配置原子替换后才提交已确认状态；已保存与运行配置分开。旧 JSON 的 ID 和有效字段保留。密码使用 Windows DPAPI 存储；旧明文只在明确保存时迁移，错误和日志均不打印密码。配置文件外部变更或 revision 冲突拒绝覆盖，要求重新读取并重做修改。

## 操作规格

| 操作 | 校验与提交 | 成功 | 失败/退出 |
| --- | --- | --- | --- |
| 新增/编辑挂载 | 名称、合法 remote、存在 remote、挂载点、重复名称/点、缓存枚举；独立保存 | 原子保存，列表按稳定 ID 更新；不自动运行 | 字段/业务错误说明具体原因；保持所有输入；取消先确认放弃 |
| 删除配置 | 确认名称、说明不删除远端文件；运行中拒绝 | 移除配置与停止实例条目 | 保留对象；先停止再重试 |
| 启动挂载 | EXE/WinFsp/remote/挂载点就绪；同对象去重 | 实际挂载位置出现、进程存活才显示就绪 | 失败或超时保留可追踪实例与日志，不报假成功 |
| 停止挂载 | 先显示停止中；请求停止本实例 | 确认进程退出及挂载位置消失 | 未确认则失败，保留引用与再次停止入口 |
| 保存设置 | 独立草稿；检验版本、路径、认证、延迟、revision；连接变更要求相关实例停止 | 文件与注册表提交/读回一致，普通偏好不重启无关进程 | 保留草稿与原事实；失败回滚，回滚失败说明实际状态 |
| 启动/停止 GUI | 端口占用检查；当前实例 HTTP/RC 就绪检查 | 就绪/停止由真实结果确认 | 启动失败和就绪延迟可查看；不会把其他进程的端口当成功 |
| 打开网页/挂载/日志 | 仅打开可达目标；GUI 要求就绪 | 系统浏览器/资源管理器打开 | 系统打开失败给出路径/原因，不静默吞掉 |
| 全部启停 | 每个对象独立结果，已运行项不重复启动 | 显示成功与失败对象 | 失败项仍可单独处理，不把部分成功称作全部成功 |
| 检查更新 | 仅访问 `https://api.github.com` 的 Releases 列表；忽略草稿与预发布；按语义化版本比较；只接受 GitHub 域名内的发布/资产链接 | 显示最新正式版本、发布时间、说明与资产；有新版本时状态与托盘提醒一致 | 超时、限流或解析失败显示具体原因；启动检查不弹错误气泡，手动检查可重试 |
| 打开下载链接 | 仅打开 HTTPS 发布页或安装包资产链接 | 系统浏览器打开；优先 `rclone_tray_setup.exe`，否则版本发布页 | 无链接时按钮禁用，不猜测地址 |
| 重新读取配置 | 外部修复损坏文件后明确读取 | 更新基线与环境；不丢失运行身份 | 文件仍坏则继续禁止保存，不提供静默重置 |
| 退出应用 | 先处理草稿；说明运行影响；阻止新操作并取消延迟任务 | 所有拥有实例确认停止后销毁前端与托盘宿主 | 留窗口与进程引用，允许再次停止；不强杀其他应用实例 |

系统自启的自动挂载仅在 `--autostart` 时触发，且全局 `auto_mount_on_boot` 与逐项 `auto_mount` 同时为真；手动打开不意外挂载。GUI 的 `gui_auto_start` 表达“随应用启动”，适用于两类启动。退出和偏好更新取消尚未执行的旧计划。

## 运行与并发

状态：已停止 → 启动中 → 就绪；失败进入失败态；就绪/启动中 → 停止中 → 已停止或失败。进程存活不等于就绪。进程异常退出在后台读回并更新同一对象状态。

后台应用操作串行化，界面线程不做阻塞 I/O；busy 按对象/动作表达，队列等待不编造进度。晚到结果只更新事实和结果提示，不重新打开已关闭流程；写入不能因用户取消等待而被假装撤销。运行动作与草稿取消互不冒充。

## UI 与键盘

当前前端为 `src/ui.rs`（Rust / Win32），`src/ui_style.rs` 集中管理调色板与 GDI 绘制。功能图标使用系统图标字体 `Segoe Fluent Icons`（Windows 10 回退 `Segoe MDL2 Assets`）的字形，不再手绘路径；侧栏标志使用 rclone 官方标志（透明 `assets/mark.ico`），窗口/托盘/EXE 使用同源 `assets/icon.ico`。遵循《Tern · Stencil 设计参考》：主背景 #101114、侧栏 #17191E、面板 #1B1D24、输入框 #16181D，强调色 #A78BFA；正文 #E6E7EB、次级文字 #B4B6C0。深色默认，浅色与跟随系统沿用相同层次。

材质采用可选 Windows DWM 标题栏背景与圆角；内容区使用不同亮度的实色表面，不宣称为桌面穿透或全窗口 Acrylic 模糊。DWM 不支持时内容仍可读、可操作。「减少动态与材质效果」沿用 `reduce_motion` 配置，关闭原生窗口转场和标题栏材质，无配置格式迁移。

控件保留原生 HWND、稳定 ID 与通知。按钮 owner-draw 区分 primary / secondary / ghost / danger，统一系统图标字形，提供悬停、按下、禁用与键盘焦点；复选框保留原生自动切换语义，自绘表面。只读下拉菜单使用同一调色板，编辑组合框仍支持手动输入。挂载列表每行 76px，名称、路径、省略号和状态词配合颜色，完整路径在可复制的详情区显示。

使用系统 `Microsoft YaHei UI`，标题 24px、正文 14px、辅助信息 12px，按窗口 DPI 缩放。按钮 32–40px、圆角 6–8px，间距遵循 4px 基础体系。表单保留取消确认、保存失败保留输入、主题草稿即时预览、明确保存后才落盘的规则。

键盘由 Win32 `IsDialogMessage` 提供 Tab / Shift+Tab 导航；保留 Ctrl+F 搜索、Ctrl+S 保存、列表双击编辑及 Delete 删除。新增/编辑使用独立 owner 窗口，关闭前处理未保存草稿；文件选择与危险操作确认沿用系统对话框。

主窗口默认 1180×840、最小 720×480，编辑器默认 700×780、最小 460×480（逻辑像素）；超出工作区时缩至可见范围。侧栏 192px，可手动折叠为 64px，窗口宽度不足 1000px 自动折叠。内容宽度不足 760px 时挂载详情移至列表下方、操作栏换行，全部功能通过滚动可达，不隐藏详情或重要操作。底部状态条固定并置于滚动表面之上；切页重绘所有控件，避免旧选中态残留。

## 验证追踪

沿用项目计划 AC-01 至 AC-16；源码/接口检查不能替代真实 UI、挂载、浏览器或注册表验证。新旧 GUI 命令分支的静态支持与实测覆盖分开记录。系统登录启动若没有重启证据只能标记未验证，不能用模拟 `--autostart` 冒充真实开机。
